# Font ospitati sul sito

Servire i font da qui (invece che da Google Fonts) evita di trasferire l'indirizzo IP dei visitatori a Google
e rende il sito più veloce. Solo il sottoinsieme *latin* (copre l'italiano e l'inglese), in formato WOFF2 variabile.

| File | Famiglia | Pesi | Licenza |
|---|---|---|---|
| `figtree-latin.woff2` | [Figtree](https://fonts.google.com/specimen/Figtree) | 400–900 | SIL Open Font License 1.1 |
| `roboto-mono-latin.woff2` | [Roboto Mono](https://fonts.google.com/specimen/Roboto+Mono) | 400–700 | SIL Open Font License 1.1 (Apache 2.0 per le versioni più vecchie) |

Le licenze permettono l'uso e la ridistribuzione, anche commerciale, a patto di non vendere i font da soli.
